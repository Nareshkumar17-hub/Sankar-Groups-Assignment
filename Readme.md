# Taskflow - SaaS Landing Page

## About

Taskflow is a responsive SaaS landing page designed to help users organise tasks, manage projects, and improve productivity.

## Features

- Responsive navigation bar
- Hero section
- Features section
- How It Works section
- Pricing section
- Contact form with front-end validation
- Responsive footer

## Technologies Used

- HTML
- Tailwind CSS
- JavaScript
- Font Awesome

## How to Run

1. Download the project folder.
2. Open index.html in a web browser.

## Design Choices

The website uses a navy, cream, and yellow colour palette. The layout is designed to be clean, simple, and responsive across desktop and mobile screens.I personally like this yellow and navy combination.


### HOW I CODE 

## NavBar 

   I used tailwind for responsive and used javascript "classlist.toggle()" for functionality 
## Contact Form

The contact form demonstrates front-end validation and a success message. It does not send data to a backend. I used JavaScript's checkValidity() method to validate the contact form. 

## Challenges i faced 

I used HTML, Tailwind CSS, and JavaScript to build the landing page. Writing and organising the HTML took more time than I expected, and I had to repeat some parts of the code.

I considered using React but decided it wasn't necessary for a simple landing page. However, writing everything in HTML took quite a bit of time.
